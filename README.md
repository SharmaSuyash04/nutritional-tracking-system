# Nutritional Tracking System 🥗

A smart dietary monitoring platform designed to simplify food logging, analyze nutritional intake, and evaluate daily consumption against WHO dietary guidelines.

---

##  Architecture & Tech Stack

- **Frontend:** React (Vite), Material UI, Chart.js / Recharts
- **Backend:** FastAPI (Python), Axios, USDA FoodData Central & Edamam APIs
- **Database:** MySQL
